Information / Accessibility

Accessibility Statement

Wardrobe Alpha Edge aims to provide a clear, usable experience across desktop, tablet and mobile devices.

Our approach

We aim to use readable typography, logical navigation, meaningful link labels, responsive layouts, adequate contrast and semantic page structure. The website also includes reduced-motion considerations for visitors who prefer less animation.

Images and content

Where images communicate information, descriptive alternative text is used where practical. Decorative images should not be relied upon to understand essential instructions. Editorial content is structured with headings and paragraphs to support easier scanning.

Keyboard and responsive use

We work toward usable navigation with common keyboard interactions and responsive layouts. Browser zoom and device text settings should remain usable without unnecessary horizontal scrolling on supported pages.

Feedback

Accessibility is an ongoing process. If you encounter a barrier, broken interaction, unreadable contrast, missing alternative text or another issue, please contact us with the page address and a short description so we can investigate.
